> 对照 [design.md](design.md) 检查单和 [game-design.md](game-design.md) 十条，记录当前十关的问题和改进方向。
>
> **本文只规划，不代替产品规格。** 改某一关时：先读该关的 `design.md` §5 规格，再按本节动手；改完把本页对应项勾掉，并回写规格。

> 约束不变：一个游戏一种功能、不混装、不吹牛。范式成立但空等 → 改手感，不叠第二种任务。

## 整套先修的三刀（跨关）

这些不是某一关独有。逐关改时能顺手带上的就带，不要单独开一个「重构全部生命系统」的大 PR，除非正在改那一关。

1. **三命容易掐断心流。** 刚热手就出局，技能原子还没串到下一档。街机关更适合「一局计时」或「错了略放宽、对了再收紧」。命可以留，但不要当唯一结束条件。
2. **难度曲线太平。** 文档要求锯齿：紧一段、松一口。多数关永远同一档 → 技能涨了、挑战不涨 → burnout。
3. **抑制控制四关手感撞车。** 色字 / 反向反应 / 中间箭头都是「看刺激、点左右、三命」。红灯停因车在动差异最大。四关都留，但节奏和冲突必须更不像。

MDA：机制都有了，动态（连击、加速、卡关）偏弱；体验几乎只吃 Challenge，Sensation 只有大字反馈。

**动手顺序（不换关、只改现有）：**

| 序 | 关 | 为什么先改 | 状态 |
| --- | --- | --- | --- |
| 1 | 反向反应 | 空档最长，最违反「无空等」 | 待做 |
| 2 | 看点数 | 每题 2.3s 看答案，一分钟局里大量时间不玩 | 待做 |
| 3 | 反向色字 | 连对加速，成本低、结构已是街机 | 已改玩法（黑字+底色；选项字对底色、底色干扰；每题重排；固定 2 秒；−10 未做） |
| 4 | 任务切换 | 同上，3 秒太松 | 待做 |
| 5 | 红灯停 | 已经最好玩，补封顶 | 待做 |
| 6 | 舒尔特 | 5×5 之后要有下一档 | 待做 |
| 7 | N-Back | 加快 SOA、让人摸到 3-Back | 待做 |
| 8 | 追踪异色球 | 点选限时 / 中段检查，避免纯旁观 | 待做 |
| 9 | 中间箭头 | 已经自适应；加速后减弱 burst、考虑计时局 | 待做 |
| 10 | 汉诺塔 | 堵住非最优混过；不要街机化 | 待做 |

## 1. 反向色字 · Stroop

**规格：** `design.md` §5.1 · `scripts/Stroop.gd`  
**现状：** 题目是有颜色的字（字≠色）；点选项上的字对题目的字体颜色；选项底色是干扰且每题重排；固定 2 秒。错题 −10 未做。

| 检查项 | 现状 |
| --- | --- |
| 知道干什么 | 过关 |
| 立刻反馈 | 过关 |
| 无空等 | 基本过关 |
| 难度会涨 | **不过**：永远 2 秒、永远 4 色 |
| 一种冲突 | 过关 |

**问题**

- 开局有 Challenge，几分钟后同一首歌。
- 速度分可能诱导乱点（`design.md` §8 已记）。
- `_burst_feedback` 在 2 秒节奏里勉强；再加速会挡下一题。

**改进方向**

- 连对缩短时限：2.0 → 下限约 0.9，每 4 连 −0.08s，点错 +0.05s（抄中间箭头）。
- 不要加第五种颜色，不要再叠一套规则。
- 若实玩确认乱点：错题改为 −10，而不是只扣命。
- 可加极少量**一致试次**（字色相同），让「抑制」重新必要。现在 100% 冲突，大脑会改成「永远反着读」。这是范式内部变体，不是第二种功能。

- [x] 连对加速改为固定 2 秒（按「时间正常一点」）
- [x] 题目：放大的彩色字（字≠色）；点选项的字 = 题目的字体颜色
- [x] 选项底色作干扰，每题重排字和底
- [ ] 决定：错题是否 −10（约定先不做）
- [x] 回写 `design.md` §5.1

## 2. 反向反应 · Go/No-Go

**规格：** `design.md` §5.4 · `scripts/GoNoGo.gd`  
**现状：** 绿点红停，显示 1.0s，间隔 **0.9–1.4s**，Go 75%，连对 10 次规则反转。

**问题**

- 空等是这关最大的洞：有效决策约 1 秒，空档几乎一样长。
- 动态是「多数时候连点绿」，No-Go 稀疏，Challenge 不够。
- 规则反转是好原子，但前面要先熬一段无聊。
- `design.md` 已写「间隔偏稳，可把 GAP 下调」。

**改进方向**

- `GAP_MIN/MAX` 收到 **0.35–0.6s**。
- Go 比例 75% → **60–65%**，让忍住成为主菜。
- 反转不要等 10 连对：改成第 6–9 题窗口内必翻，或可见倒计时。
- 显示时间可随连对从 1.0 收到 0.55。
- 不要在圆上再叠数字/位置（那是 N-Back）。

- [ ] 缩短间隔
- [ ] 提高 No-Go 比例
- [ ] 更早 / 更可预期的规则反转
- [ ] 可选：显示时间随连对缩短
- [ ] 回写 `design.md` §5.4

## 3. 红灯停 · Stop-signal

**规格：** `design.md` §5.5 · `scripts/StopSignal.gd`  
**现状：** 车 1.2–2.0s 开完，绿线 72% 才能冲，红灯 50%，间隔 0.55–0.9s。合集里最像游戏。

**问题**

- 难度不涨：第 20 轮和第 2 轮是同一套车。行驶时间随机，不随技术收紧。
- 三命仍会中断热手。
- 文档玩法仍写「约 1/4 的轮次」亮红灯，代码已是 `STOP_RATIO := 0.5`。先改文档。

**改进方向**

- 连对缩短行驶：2.0s → 下限约 1.0s，绿线不变，窗口变窄。
- 红灯出现点随连对往绿线挤（更晚亮 = 更难刹）。仍是 stop-signal 的 SSD，不混装。
- 间隔收到 0.35–0.55s。
- Sensation：冲过时车冲出、红灯误冲急闪。
- 优先涨封顶，不改玩法骨架。

- [ ] 文档与代码的红灯比例对齐
- [ ] 连对缩短行驶 / 红灯更晚
- [ ] 缩短试次间隔
- [ ] 可选：冲过 / 误冲的视觉加强
- [ ] 回写 `design.md` §5.5

## 4. 中间箭头 · Flanker

**规格：** `design.md` §5.9 · `scripts/Flanker.gd`  
**现状：** 1.15→0.52s，不一致 55→82%，间隔 0.22s。十关里最符合检查单的街机。

**问题**

- 手感太像加速版色字。
- 三命：刚加速完容易死。
- 下限 0.52s 时 burst 会盖住箭头。
- 五支箭头一样大，中间不够「中间」。

**改进方向**

- 中间箭头略大或略亮（不要描到变成「看金色」）。
- 命改为 60 秒一局或 5 命。
- 加速后关掉大字 burst，只留中间变色 + 短闪。
- 封顶后再加一档：7 支箭头，或侧翼间距缩小。仍是 Flanker。

- [ ] 中间箭头可辨，但不靠描边作弊
- [ ] 加速后减弱 / 关掉 burst
- [ ] 结束条件：计时局或加命
- [ ] 可选：7 箭 / 更挤的侧翼
- [ ] 回写 `design.md` §5.9

## 5. 舒尔特方格

**规格：** `design.md` §5.2 · `scripts/Schulte.gd`  
**现状：** 永远 5×5，点 1–25，计时 + 失误。一局里连续搜索，不断档。

**问题**

- **封顶死了。** 熟了只跟自己的秒数比，没有新技能原子。
- 点错不中断是对的（保心流），但没有难度回馈。

**改进方向（只加搜索难度）：**

- 通关后出现 6×6、7×7；或完成 5×5 给一局 4×4「我变强了」，再上 6×6（锯齿）。
- 格子必须保持不动。微微换位会变成 MOT，禁止。
- 可选：限时点完（如 40s），失败重排，而不只刷最快纪录。

- [ ] 5×5 之后的下一档（至少 6×6）
- [ ] 可选：通关后的呼吸关 4×4
- [ ] 可选：限时模式
- [ ] 回写 `design.md` §5.2

## 6. 追踪异色球 · MOT

**规格：** `design.md` §5.8 · `scripts/Track.gd`  
**现状：** 高亮 1.5s → 跑约 13–20s → 停下点选。6–12 球，移速 270–420。

**问题**

- 跑的时候不会死，Challenge 全堆在最后点选。
- 动态是「盯十几秒再考试」。对 MOT 合理，对心流偏长。
- 追踪过程没有即时反馈。

**改进方向**

- 点选限时约 3s，逼出「真的在追」而不是最后猜。
- 或把长移动切成两段（跑一段 → 瞬停点 1 个 → 再跑），仍是追踪，反馈提前。
- 12 球之后用「异色 +1」或更小的球涨封顶，**不要再拉长移动时间**。
- 高亮 1.5s 可随球数略减。
- 不要在跑动中让球互撞或加第二种任务。

- [ ] 点选限时，或中段检查
- [ ] 12 球后的封顶（异色/更小），不靠加时
- [ ] 可选：高亮随球数缩短
- [ ] 回写 `design.md` §5.8

## 7. N-Back

**规格：** `design.md` §5.6 · `scripts/NBack.gd`  
**现状：** SOA 2.5s（亮 0.9s），N=2–4，连对 10 升、连错 3 降，开局说明 + 开始。

**问题**

- 测验感强。2.5s 对工作记忆必要，对街机太稀。
- 升 N 要 10 连，三命往往还在 2-Back 就死，封顶 4 摸不到。
- Dual N-Back 规格写「留到后续」：**先不要加**（混装）。

**改进方向**

- SOA 2.5 → **约 1.8s**（亮仍 0.7–0.9s）。
- 升 N：10 连 → **6 连**；降 N 保持 3 连错。
- 三命 → 一局固定刺激次数（如 40–50），或更多容错，否则热不起来。
- 对/错标在刚亮的那格上，不要只靠大字。

- [ ] 加快 SOA
- [ ] 降低升 N 门槛
- [ ] 结束条件不再是三命速死
- [ ] 格子上的对错反馈
- [ ] 回写 `design.md` §5.6
- [ ] Dual N-Back 仍不做

## 8. 看点数 · Dots

**规格：** `design.md` §5.3 · `scripts/Dots.gd`  
**现状：** 60s 局，闪 0.6→0.35s 再加点；对完回显 **1.8s + 清空 0.5s**。自适应本身是对的。

**问题**

- 每题约 2.3s 不玩。一分钟局里大量时间在看答案。
- 这是当时为「看清点了几个」加的，和心流冲突。
- 回显时 60 秒暂停，改短回显会自然变多题。

**改进方向**

- 对了：回显 **0.6–0.8s**，清空 **0.2s**，或对了直接下一题。
- 错了：才拉长对照（可保留接近 1.8s）。
- 不要改成「点哪个格子有点」。

- [ ] 对了短回显 / 错了才长对照
- [ ] 清空时间缩短
- [ ] 回写 `design.md` §5.3

## 9. 任务切换 · Switch

**规格：** `design.md` §5.7 · `scripts/Switch.gd`  
**现状：** 蓝=奇偶 / 橙=比 5，每 2–4 题切，每题 **3 秒**，无加速。开局说明 + 开始按钮合理。

**问题**

- 判断本身太容易，3 秒太松。
- Challenge 只在切规则那一拍，其余是重复。
- 没有难度 ramp。

**改进方向**

- 时限 3.0 → 开局约 1.6s，连对收到约 0.9s。
- 切换更密：每 2–4 → **每 1–3**。
- 不要加「假切」（色块闪但规则不变）——那是欺骗，不是灵活性。
- 不要第三套规则（混装）。刺激仍是 1–9 无 5。
- 切对 +20 已标出灵活性；HUD 可显示「距下次切换」以保持知情，但不要变成额外记忆负荷。

- [ ] 连对加速时限
- [ ] 切换更密
- [ ] 不加假切、不加第三规则
- [ ] 回写 `design.md` §5.7

## 10. 汉诺塔

**规格：** `design.md` §5.10 · `scripts/Hanoi.gd`  
**现状：** 3→6 盘，最优才加盘，非最优也能过；记住关数。

**问题**

- 3 盘几乎没 Challenge。
- 非最优可过 → 可以一直混，计划被绕开。
- 6 盘 63 步是**解谜心流**，不要用街机节奏衡量，也不要改成限时闪电手。
- 6 盘后半有 Submission（耗着）风险，可接受，用「堵住混过」解决，不用随机失败。

**改进方向**

- 步数超过最优 ×1.5：**不能算过关**，必须复位重来（或强制不进下一盘）。
- 最优通关后可展示路径（反馈）；玩的时候不要提示下一步。
- 不要加成败随机、不要限时。
- 有存档时进最新关，已经做了。

- [ ] 非最优超步数不能混过
- [ ] 可选：过关后展示最优路径
- [ ] 不加限时、不加随机
- [ ] 回写 `design.md` §5.10

## 改完一关的收尾

1. 更新本节对应关的勾选和「现状」一句。
2. 回写 `design.md` 该关规格（数值以代码为准）。
3. 若改了结束条件（三命 → 计时局），同步 help 文案。
4. 不在本页发明新范式；要换关走 `design.md` 第 1 节「宁可换关」。
